# USR-005：本地与云端数据同步

**类型**：feature / web + backend asset
**优先级**：P1
**依赖**：USR-001、USR-002
**状态**：not started
**建议标签**：`user-system`, `sync`, `data-integrity`, `web`

## Problem

统计数据目前只在浏览器本地，账号资产尚不存在。用户需要逐项同步题库设置、游玩记录和曲库设置，却没有单侧直接同步、冲突比较、整体覆盖确认或快照过期保护。

## Required outcome

提供 `/account/sync` 的可扩展数据项列表。每一项独立显示本地/云端状态、更新时间和可用操作；单侧存在时可直接单向同步，双侧冲突时用户在可读差异预览中选择保留一个完整版本，任何情况下不自动合并。

## In scope

- 定义并实现题库设置、游玩记录、曲库设置的数据项注册表、版本/更新时间/来源摘要和云端账号资产边界。
- “同步至云端”“同步至本地”“查看当前数据”的按项操作；同步至本地覆盖前二次确认，取消不改数据。
- 冲突预览展示具体新增/删除/修改项、更新时间、来源和总数；游玩记录只展示数量、时间范围等统计摘要，不列完整记录。
- 差异过多时的分类折叠或分页；预览打开期间的本地/云端版本校验、过期提示“数据已更新，请重新载入”和重新载入流程。
- 覆盖操作的原子性、失败保留两侧原数据、重试、处理中禁用当前项而不阻塞其他数据项。
- 与现有 `apps/web/src/stats/` 的导入/替换边界对接：产品同步使用整体版本选择，不直接暴露合并按钮；保留现有本地数据格式兼容策略。
- 权限过期、网络失败、云端不可用、空数据和单侧缺失的独立反馈。

## Out of scope

- 自动后台同步、字段级合并、跨账号共享、完整游玩记录冲突列表或秘密字段同步。
- 账号认证和会话实现（USR-002）、同步页面通用外壳之外的个人资料页面（USR-004）。
- 修改现有统计聚合指标或多人对局规则；只提供同步所需的摘要/替换适配。

## Acceptance criteria

- [ ] 每个数据项独立展示本地状态、云端状态、同步时间和操作；一个项目失败/加载不会清空或阻塞其他项目。
- [ ] 题库/曲库设置可查看当前数据并复用已有查看组件；游玩记录不显示“查看当前数据”，继续引导到现有统计页。
- [ ] 仅一侧存在时可直接执行对应的单向同步；两侧一致时不要求无意义覆盖；同步结果明确反馈。
- [ ] 双侧冲突预览列出具体变更项和总数；游玩记录只显示统计摘要；用户只能选择“保留本地”或“保留云端”的整体版本。
- [ ] 同步至本地覆盖前必须二次确认；取消无数据变化；请求失败保持两侧原数据并允许重试。
- [ ] 预览期间任一版本变化会使预览过期、禁止覆盖并要求重新载入；重新载入后差异和可选版本来自最新快照。
- [ ] 权限过期回认证入口；网络/服务失败保留当前页面和草稿；不会把密码、密保答案或会话令牌放进同步摘要。
- [ ] 现有本地统计记录可继续读取；同步替换使用事务/原子边界，页面不调用产品禁止的合并操作。

## Test plan

- 数据项状态机测试：单侧、相同、冲突、过期、取消、失败、重试和并行项目。
- 差异摘要 fixture 测试：具体新增/删除/修改项、分页/折叠计数、游玩记录统计摘要不含完整记录。
- 浏览器测试覆盖二次确认、快照过期重新载入、刷新/权限失效和移动端列表布局。
- API 并发覆盖/版本校验集成测试；现有 `apps/web/src/stats` 测试、`pnpm test`、`pnpm typecheck` 和构建。

## Dependencies and follow-ups

依赖 `USR-001` 的版本/差异契约和 `USR-002` 的账号资产鉴权。完成后由 `USR-008` 验证数据完整性和回滚；新增数据项需只扩展注册表，不改变已有项目行为。
