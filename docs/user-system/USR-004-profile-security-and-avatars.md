# USR-004：个人资料、密保与头像

**类型**：feature / web + data
**优先级**：P1
**依赖**：USR-001、USR-002
**状态**：not started
**建议标签**：`user-system`, `profile`, `avatar`, `web`

## Problem

用户没有个人信息页，无法维护多人游戏使用名称、密保问题或头像；角色素材虽然有稳定 ID 和首次出场数据，但没有面向账号头像选择的默认清单、可用性过滤和解锁状态。

## Required outcome

实现 `/account/profile`、`/account/security-questions` 和 `/account/change-password`，以及可复用的个人设置外壳。用户能看到不可编辑的用户名/UID，编辑多人游戏使用名称和头像，设置三个不重复的密保问题，并用原密码修改密码；头像列表稳定、可访问且在素材失效时可回退。

## In scope

- 个人设置桌面左侧导航、移动端选择器/标签、当前账号信息和退出入口的承载区；未保存修改切换/返回/退出均需确认。
- 个人资料读取与保存：头像、用户名、多人游戏使用名称、UID；名称允许汉字/字母/数字，1 至 10 字符，不允许空格和特殊字符。
- 默认头像素材清单及其发布可用性校验；注册时从有效默认头像中随机选择初始头像；角色头像从 `packages/data/src/` 的稳定角色 ID/首次出场字段生成候选。
- 头像顺序为默认清单顺序，再按首次出场时间、稳定角色 ID；缺失/不可用不显示；默认头像解锁，角色头像按猜出角色解锁；当前头像失效回退第一个有效默认头像。
- 头像浮层的键盘、Esc、外部点击关闭、滚动和解锁状态可访问名称；保存成功即时反映，后台解锁保存失败不阻塞游戏并在页面提示重试。
- 密保问题选项、三个不重复选择、非空答案、保存前校验、答案原文保留和离开确认。
- 修改密码页包含原密码、新密码和确认新密码，复用注册密码规则；成功后其他设备会话失效而当前设备保持登录，失败保留输入并明确反馈。
- 管理员/本人读取的秘密字段只返回“已设置/未设置”状态，绝不返回答案原文。

## Out of scope

- 账号/密码/密保答案的服务端存储和归一化算法（USR-002）。
- 数据同步（USR-005）、管理员维护动作（USR-006）和房间身份切换（USR-007）。
- 新增角色素材、未经授权的临时图片或更改现有角色首次出场数据。

## Likely code areas

- `apps/web/src/app/account/profile/`
- `apps/web/src/app/account/security-questions/`
- `apps/web/src/components/CharacterAvatar.tsx`、新建头像选择器/设置外壳组件
- `packages/data/src/index.ts`、`packages/data/src/schema.ts`、素材清单目录
- `apps/web/src/lib/api.ts`、`apps/web/src/hooks/`
- 资料/头像组件测试和素材校验测试

## Acceptance criteria

- [ ] 个人信息页展示头像、用户名、多人游戏使用名称和完整 UID；用户名/UID不可编辑，名称非法时不发起保存。
- [ ] 注册初始头像从有效默认头像中随机选择；默认头像候选严格按清单顺序，角色候选按首次出场时间再按稳定 ID；缺失/不可用素材不存在于 DOM；候选排序在重复加载和不同浏览器一致。
- [ ] 默认头像可选且始终解锁；未解锁角色头像明确标记且不可点击；猜出角色后的解锁状态能在刷新后恢复；当前头像失效自动选第一个有效默认头像并提示修复。
- [ ] 头像浮层支持键盘打开、焦点保持、Esc/外部点击关闭、窄屏内部滚动和读屏名称，不推动页面布局。
- [ ] 密保页提供七个固定问题选项，三个问题不能重复、答案不能为空；保存/离开行为和全局成功/失败提示与总规范一致。
- [ ] 修改密码必须验证原密码、新密码规则和两次输入一致；成功后当前设备保持登录、其他设备会话失效，失败时输入可恢复。
- [ ] 页面永不展示密码或密保答案原文；服务端失败保留草稿，解锁保存失败可重试且不阻塞当前游戏。
- [ ] 桌面/移动端 320px 宽度无溢出，未保存切换/返回/退出确认可取消且不丢草稿。

## Test plan

- 头像排序的固定 fixture 测试：清单顺序、相同首次出场时间的稳定 ID、缺失素材过滤、失效回退。
- 资料、密保和改密表单测试：字符长度（含汉字）、特殊字符、重复问题、原密码错误、跨设备会话失效、未保存离开和服务端错误保留输入。
- 键盘/读屏与响应式浏览器测试；现有 `CharacterAvatar` 行为回归。
- `pnpm test`、`pnpm typecheck`、素材 schema/数据校验和构建。

## Dependencies and follow-ups

依赖 `USR-001` 的资料契约和 `USR-002` 的资料/密保 API。实现时与 `USR-003` 共用认证状态和页面外壳接口，但两者不构成先后依赖。完成后 `USR-006` 可以复用资料和头像模型，`USR-007` 可以读取多人名称和当前头像；素材清单变更需同步发布说明。
