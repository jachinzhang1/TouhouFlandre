# 角色像素肖像

本目录收录“东方全角色像素肖像素材包”中的 142 张透明 PNG，用于 TouhouFlandre 的角色头像和后续题库扩展。

- 原作者：苗库里
- 作者主页：https://space.bilibili.com/152309938
- 允许用途：个人及非商业用途，包括同人作品、免费游戏、网站等
- 原始规格：2048 × 2048，32 位透明 PNG
- 文件命名：保留素材包原始编号与角色名称

这些图片不适用仓库的 MIT 许可证，版权仍归原作者所有。复用或再分发前请确认并遵守作者的使用条件，同时保留署名。

当前题库与头像文件的对应关系维护在 `packages/data/src/characters.demo.json` 的 `avatarUrl` 字段中。运行 `pnpm seed` 后，API 会将头像地址与角色数据一起提供给所有前端页面。
