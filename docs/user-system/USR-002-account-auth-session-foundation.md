# USR-002：账号、认证、UID 与会话基础

**类型**：feature / backend foundation
**优先级**：P0
**依赖**：USR-001
**状态**：not started
**建议标签**：`user-system`, `auth`, `security`, `backend`

## Problem

当前服务端只有房间游客令牌，没有持久账号、密码、密保、管理员权限或可撤销的登录会话。页面无法可靠判断账号状态，也无法实现 UID 永不复用、失败冷却、一次性重置授权和跨设备会话失效。

## Required outcome

实现服务端账号与认证领域，使账号、权限、会话和风控状态成为唯一权威来源。注册、登录、改密、密保找回、管理员发起重置、停用账号和登出都能按 `USR-001` 契约产生稳定结果；数据和秘密值按安全边界存储与返回。

## In scope

- 账号持久化、管理员角色、账号状态“正常/停用”、注册时间和最近成功登录时间。
- 管理员账号由部署/运维流程初始化和轮换；仓库只提供可重复的配置/引导边界，不保存明文初始凭据或生产账号数据。
- 用户名大小写精确匹配与唯一性约束；停用账号禁止登录并使已有会话失效。
- 仅数字和大写字母的 UID 分配：管理员 `000000`，普通用户从 `000001` 起，按 D-003 扩展至最多 15 位；并发注册下不重复、不回收，达到配置上限时返回“注册暂停”。
- 密码注册、登录、修改和重置；密码格式沿用总规范，密码成功修改/重置后撤销其他设备会话，改密当前会话保持有效。
- 三个密保问题/答案的安全存储与比较预处理（全角/半角归一化、首尾空格、大小写敏感）。密保验证成功发放 15 分钟、一次性重置授权。
- 管理员一次性重置凭据的签发、哈希保存、15 分钟有效期、一次消费和撤销；只返回一次原始凭据。
- 登录、密保和管理员敏感操作的服务端失败计数、冷却持久化/可恢复读取和成功清零策略；网络失败与未提交确认不计数。
- 会话创建、当前会话登出、按用户/设备撤销会话和权限中间件；会话过期返回契约错误。
- 安全日志/指标中只记录操作类型、结果和关联 ID，不记录密码、密保答案、原始重置凭据或完整会话令牌。

## Out of scope

- 认证页面和个人设置组件（USR-003、USR-004）。
- 管理员列表页面及清除密保/强制下线的页面确认与操作编排（USR-006；本 Issue 只提供可调用的服务端原语）。
- 云端用户资产的具体数据格式、冲突比较和本地 IndexedDB UI（USR-005）。
- 多人房间使用账号资料和退出时离开编排（USR-007）。

## Likely code areas

- `apps/api/migrations/`、`apps/api/sql/queries/`
- `apps/api/internal/handler/`（认证中间件、错误映射、服务端实现）
- `apps/api/internal/config/`（UID 上限、冷却和会话配置）
- `apps/api/internal/generated/`（由 SQLC/OpenAPI 生成）
- `apps/api/internal/server/` 及认证/安全集成测试

## Acceptance criteria

- [ ] 注册能原子分配 UID；覆盖数字段、字母前缀进位、n 位耗尽扩展、15 位上限、并发注册和暂停注册，且 UID 不回收。
- [ ] `Alice` 与 `alice` 可分别注册并分别登录；同一大小写的重复注册被拒绝；登录错误不泄露账号存在性。
- [ ] 停用账号不能新登录，已有会话校验失败；账号在多人房间中的后续离开事件由 USR-007 消费。
- [ ] 密保答案按约定归一化但保留大小写；正确校验只产生一个 15 分钟授权，授权成功重置后/过期后不可复用。
- [ ] 登录错误 5 次锁定 15 分钟，密保错误 5 次锁定 30 分钟，管理员敏感操作原语支持按操作类型 3 次锁定 10 分钟；刷新或重启服务不能绕过有效冷却。
- [ ] 密码修改/重置撤销其他设备会话；普通用户当前会话保持，按用户强制撤销可以包含当前管理员会话。
- [ ] 任何 API 响应、错误、日志和测试 fixture 都不包含密码、密保答案或原始令牌；一次性管理员凭据只在签发响应中出现一次。
- [ ] 迁移、查询、服务端单元/集成测试可在空库和已有多人数据上重复执行，且不破坏游客鉴权。
- [ ] 管理员初始化/轮换有运维入口且不会把初始密码或生产账号写入仓库、生成物或测试日志。

## Test plan

- UID 属性测试/表驱动测试：边界值、进位、扩位、上限暂停和并发事务。
- 认证集成测试：大小写、密码错误、停用、会话撤销、改密保留当前设备、跨设备失效。
- 风控测试：各计数键互相隔离、冷却倒计时跨刷新/重启保持、成功清零、网络/取消不计数。
- 秘密泄露扫描和结构化日志断言；`go test ./...`、迁移测试和契约生成检查。

## Dependencies and follow-ups

需要 `USR-001` 的契约和错误编码。完成后解除 `USR-003`、`USR-004`、`USR-005`、`USR-006`、`USR-007`；管理员操作页面必须使用本 Issue 提供的会话/授权原语，不得复制密码逻辑。
