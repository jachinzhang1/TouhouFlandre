# USR-003：认证页面与账号入口

**类型**：feature / web
**优先级**：P0
**依赖**：USR-001、USR-002
**状态**：not started
**建议标签**：`user-system`, `web`, `authentication`

## Problem

站点没有登录、注册、找回密码或重置密码页面，也没有统一的“个人”入口和退出登录流程。用户无法从游客状态进入账号能力，失败、冷却和会话过期也没有稳定的页面反馈。

## Required outcome

实现从“个人”入口开始的认证闭环：登录、注册、忘记密码、重置密码、认证过期回目标、成功注册回登录页，以及已登录用户可发现且可确认的退出登录入口。页面只消费 `USR-002` 的服务端状态，不在浏览器自行判断密码或冷却。

## In scope

- `/account`、`/account/login`、`/account/register`、`/account/forgot-password`、`/account/reset-password` 路由及认证状态守卫。
- 登录表单、密码显示/隐藏、回车提交、字段校验、统一错误文案、停用提示、冷却倒计时和网络重试。
- 注册字段校验、精确大小写占用反馈、UID 耗尽/注册暂停提示；成功提示后返回登录页且不自动登录。
- 忘记密码获取三个问题、答案校验、错误不指出具体答案、授权过期/撤销回登录入口。
- 重置密码同时支持密保一次性授权和管理员一次性凭据；显示只读用户名，成功返回登录页，其他设备失效提示由服务端结果驱动。
- 桌面/移动端“个人”入口、登录后目标页面回跳、统一认证状态骨架/无权/服务不可用状态，以及登录用户的“退出登录”操作入口。
- 退出登录前对设置页未保存修改进行确认；常规登出清理客户端认证状态并回到登录页。

## Out of scope

- 个人资料、密保设置页和头像选择器（USR-004）。
- 数据同步页（USR-005）、管理员详情操作（USR-006）和多人房间离开编排（USR-007）。
- 新增邮箱、短信、第三方登录或自动合并数据。

- `apps/web/src/components/`（表单、认证状态、确认框）

## Acceptance criteria

- [ ] 未登录点击“个人”进入登录；需要认证的原目标在登录成功后恢复；已登录首次进入个人信息入口，导航可在桌面和移动端发现。
- [ ] 登录按大小写精确匹配；凭据错误、停用、冷却和网络错误使用不同且不泄露账号存在性的反馈，提交期间不可重复发送且失败保留输入。
- [ ] 注册校验用户名 4 至 10 位字母/数字、密码 6 至 256 位且无空格、确认密码一致；成功显示提示并返回登录页，不自动登录；注册暂停明确显示为注册不可用。
- [ ] 忘记密码只在获取问题成功后启用答案；答案比较遵循服务端规则，失败不指出具体答案；成功只进入一次性重置流程，刷新不能绕过冷却或重复授权。
- [ ] 重置密码支持两种授权来源、15 分钟过期和一次消费；成功回登录页，凭据无效/过期有明确可恢复入口，不显示内部原因。
- [ ] 已登录页面存在“退出登录”入口；有未保存修改时二次确认，取消不登出；确认后清理本地认证状态，后续受保护页面回到登录入口。
- [ ] 320px 宽度、键盘、读屏标签/错误关联、深浅色主题下无横向溢出或关键文本遮挡。

## Test plan

- React 组件/路由测试覆盖入口、回跳、表单字段、冷却计时、授权过期、重试和登出确认。
- 使用 mock API 验证停用、错误不泄露、注册成功回登录和一次性凭据不重复提交。
- Playwright 或等效浏览器验收覆盖桌面/移动 viewport、键盘完成流程、刷新冷却状态和认证守卫。
- `pnpm typecheck`、前端测试和构建。

## Dependencies and follow-ups

依赖 `USR-001` 的错误/状态契约和 `USR-002` 的服务端会话。完成后为 `USR-007` 提供可调用的客户端登出和目标房间上下文清理能力；`USR-004` 的设置外壳可复用本 Issue 的认证状态组件。
