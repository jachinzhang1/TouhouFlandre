# USR-006：管理员账号列表与详情

**类型**：feature / web + backend
**优先级**：P1
**依赖**：USR-001、USR-002、USR-004
**状态**：not started
**建议标签**：`user-system`, `admin`, `security`, `web`

## Problem

管理员页面目前只是占位页。管理员无法按 UID 或用户名检索账号、查看注册/最近登录时间和状态，也无法在需要时清除密保、发起重置或使会话失效。

## Required outcome

实现受服务端权限保护的 `/account/admin` 列表/详情工作流，支持高效检索和单账号维护。敏感操作均二次确认，管理员可以对自己执行强制下线；任何权限变化、冷却和会话失效都以可恢复状态呈现。

## In scope

- 管理员列表：UID、用户名、最近成功登录时间、按注册时间展示的“账户登录时间”、账号状态；默认 UID 升序，可切换用户名/注册时间/最近登录时间等排序，分页和状态筛选。
- 用户名大小写不敏感模糊搜索、UID 查询、空结果/加载失败/无权状态；返回详情时保留筛选、排序和分页位置。
- 详情：基本资料、密保/密码是否设置、头像解锁概况和同步状态；不得返回秘密原文。
- 非秘密资料编辑复用 `USR-004` 的校验；UID/用户名不可修改。
- 清除密保、生成管理员一次性重置凭据、强制用户下线的服务端命令与页面二次确认、结果反馈和冷却倒计时；重置凭据仅展示一次并支持复制。
- 强制下线目标为当前管理员时，使所有设备（含当前会话）失效并回登录页；目标用户在多人房间的离开事件由 `USR-007` 消费。
- 普通用户直接访问管理地址不得看到列表内容；权限失效时停止编辑并显示无权状态。

## Out of scope

- 账号停用/启用、批量操作、审计报表、角色体系扩展和封禁策略。
- 密码/密保存储和会话撤销底层原语（USR-002）；个人资料组件本身（USR-004）。
- 多人房间具体事件投影和客户端登出编排（USR-007）。

## Acceptance criteria

- [ ] 只有管理员能读取列表和详情；普通用户、过期会话和权限变化都不返回账号数据，并显示统一无权/认证状态；现有 `/admin` 提供到 `/account/admin` 的兼容跳转或等价入口。
- [ ] 列表默认 UID 升序，排序切换稳定且分页可复现；用户名模糊搜索忽略大小写，注册占用检查仍精确；详情返回后返回列表保留查询状态。
- [ ] “账户登录时间”显示注册时间，另列最近成功登录时间；状态只有正常/停用，冷却不改变状态。
- [ ] 密保/密码只显示已设置状态；清除密保、生成重置凭据、强制下线均有明确二次确认，取消不产生变化。
- [ ] 一次性重置凭据显示一次、15 分钟有效、可复制但关闭后不可再次查看；管理员不能设置/查看临时密码。
- [ ] 强制下线允许管理员对自己执行，所有会话失效后当前页回登录；目标用户的房间离开显示由后续集成验证。
- [ ] 敏感操作达到 3 次失败进入 10 分钟冷却，按钮显示倒计时；取消确认和网络错误不计数，刷新不能绕过。

## Test plan

- API 权限、排序、搜索、分页和时间字段集成测试；验证大小写模糊搜索与精确占用的差异。
- 管理员页面测试覆盖详情编辑、三类确认、凭据一次展示/复制、本人强制下线和冷却。
- 浏览器测试验证普通用户不能通过 URL/缓存绕过、移动端列表可用、返回保留筛选状态。
- 生成检查、`go test ./...`、`pnpm test`、`pnpm typecheck` 和构建。

## Dependencies and follow-ups

依赖 `USR-002` 的管理员鉴权/撤销原语、`USR-001` 的列表与错误契约和 `USR-004` 的资料模型。完成后 `USR-007` 接入强制下线/停用后的房间成员离开语义，`USR-008` 收集安全与权限证据。
