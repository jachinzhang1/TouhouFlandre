# 用户系统发布闸门

以下检查在实现完成前保持未勾选。发布负责人在执行时填写证据，不得用“看起来正常”替代命令输出、测试报告或浏览器记录。

## 契约与生成物

- [ ] `contracts/openapi/openapi.yaml` 与 WebSocket 契约包含全部用户系统状态、错误和权限边界。
- [ ] OpenAPI bundle、SQLC、前端 API 类型生成成功，`task check:generated` 无漂移；生成文件未被手工编辑。
- [ ] 契约 fixture 覆盖停用、冷却、授权过期、同步快照过期和游客多人兼容。

## 功能闭环

- [ ] 个人入口在未登录/已登录/管理员状态下均正确；认证成功能回原目标，注册成功回登录。
- [ ] 登录、密保、管理员敏感操作的失败阈值/冷却、刷新保持和成功清零符合决策记录。
- [ ] 密保和管理员重置授权均 15 分钟、一次消费；改密/重置的其他设备会话失效。
- [ ] UID 从数字段、字母进位、扩位到 15 位上限的边界和注册暂停有证据。
- [ ] 个人资料、密保、头像顺序/解锁/失效回退和未保存确认闭环。
- [ ] 同步单侧直传、冲突具体差异/统计摘要、整体覆盖、快照过期重载和失败保留原数据闭环。
- [ ] 管理员列表搜索/排序/时间字段、详情秘密边界、三类二次确认、本人强制下线闭环。
- [ ] 新多人房间使用账号身份，游客房间不切换；退出登录的成功/失败/断线均显示本人和其他成员的离开状态。

## 安全与权限

- [ ] 普通用户无法通过 URL、缓存、旧页面或 API 直接访问管理员数据/操作。
- [ ] 停用账号的新登录、已有会话和房间成员离开行为经过双会话验证。
- [ ] 响应、页面、URL、日志、指标和本地存储不含密码、密保答案、原始会话令牌或关闭后重置凭据。
- [ ] 一次性授权重放、冷却绕过、重复提交和并发 UID 分配测试通过。

## 可访问性与兼容性

- [ ] 320px、常用桌面宽度、深浅色主题和减少动态效果下无横向溢出或关键内容遮挡。
- [ ] 键盘可完成表单、提交、确认、头像浮层打开/关闭和页面导航；焦点顺序和返回可预测。
- [ ] 所有字段有可见标签，错误/成功/等待/禁用状态有文本或结构表达并可被读屏器感知。
- [ ] 现有每日题、随机题、统计页和游客多人房间回归通过。

## 运行与回滚

- [ ] 注册暂停、认证冷却、重置凭据和同步/房间异常的指标、日志和告警已部署，抽样不含秘密。
- [ ] 数据库迁移在备份副本和已有多人数据上演练成功；发布顺序和失败处理已记录。
- [ ] 用户系统开关可关闭并保留游客流程；回滚点可恢复服务而不删除账号、UID、云端资产或浏览器本地统计。
- [ ] 灰度期间已验证错误率、冷却触发、同步失败和房间离开异常没有超出预期阈值。
