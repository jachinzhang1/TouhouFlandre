# Phase 6 - 前端体验优化与会话一致性修复

> 状态：已实施
> 日期：2026-08-06
> 分支：`feature/web-ui-polish`

## 1. 目标

修复猜题搜索与会话题库快照不一致的问题，并完善搜索交互、每日题持久化、随机题重开保护、品牌视觉、状态反馈和视觉回归覆盖。

## 2. 实施范围

- `GET /api/characters/search` 支持按 `sessionId` 搜索会话绑定快照。
- 猜题搜索升级为支持键盘、指针和 ARIA 状态的 combobox，建议层通过 portal 限制在视口内。
- 每日题同日恢复完整进度并移除手动重开入口；随机题有进度时重开需确认。
- 移除复制分享入口，统一阴阳品牌图案、粗体标题、头像和加载/空/错误状态。
- 搜索页使用分段式视图与排序控件，并扩展单元、集成、E2E 和截图回归覆盖。

## 3. 运行说明

- Web 继续使用 `5173` origin，以保留现有 localStorage 会话。
- 本轮包含 Go handler 和 OpenAPI 生成物修改，API 已重启；不涉及数据库迁移。
