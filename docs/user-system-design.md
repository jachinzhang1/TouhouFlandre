# 用户系统页面与交互规范

**状态**：已确认

**版本**：1.0

**适用范围**：账号入口、认证流程、个人设置、显式数据同步和管理员账号视图

## 1. 文档目的

本文将用户系统的产品需求整理为可供设计、前端和后续接口开发共同使用的页面与交互规范。本文关注用户能看到什么、可以执行什么、每一步如何反馈，不规定数据库表、接口字段、密码哈希算法或部署方式。

文中的“必须”表示跨页面不可变的产品行为，“应”表示默认体验，“可以”表示实现时可在不改变用户目标的前提下调整。

### 1.1 用户目标

- 游客能够从站点导航进入登录、注册和找回密码流程。
- 已登录用户能够查看和维护个人资料、安全问题、密码及可选的云端数据副本。
- 管理员能够在受保护的管理视图中查看账号概况，并执行受授权的维护操作。
- 失败、等待、权限不足和未保存状态都应有清晰且可恢复的反馈。

### 1.2 功能范围

| 范围 | 目标体验 |
| --- | --- |
| 认证 | 登录、注册、忘记密码、重置密码 |
| 个人资料 | 头像、用户名、多人游戏使用名称、UID |
| 安全设置 | 密保问题与答案、修改密码 |
| 数据同步 | 题库设置、游玩记录、曲库设置等独立数据项的手动同步 |
| 管理视图 | 账号列表、账号详情和受控维护操作 |
| 站点入口 | 桌面端右上方“个人”入口，以及移动端对应入口 |

### 1.3 明确不属于本文

- API、数据库、迁移、会话令牌、加密和密码存储算法。
- 短信、邮箱、第三方登录、二次验证或自动密码找回渠道。
- 自动把本地游玩记录上传云端，或在多个设备之间自动合并数据。
- 社交关系、好友、私信、公开个人主页、账号排行榜和账号注销流程。
- 管理员审计报表、批量操作、封禁策略和权限角色体系的扩展设计。
- 账号数据库、生产账号数据和任何初始凭据进入代码仓库版本管理。

## 2. 现状基线与产品边界

### 2.1 仓库现状

- 站点当前导航为“首页、游戏、搜索、统计、公告”；桌面端为顶部导航，移动端为底部导航。
- `apps/web/src/app/admin/page.tsx` 当前是管理后台占位页，尚无账号设置页。
- 前端已经使用 Ant Design 和 Lucide，已有全局 `message` 反馈、表单错误状态、深浅色主题和移动端布局约定。
- 多人身份目前是房间范围内的游客身份；本功能将增加账号身份，但不能改变游客多人流程的既有行为。
- `/stats` 当前以浏览器本地数据为基线。只有用户主动操作“同步至云端”时，数据才进入账号资产。

### 2.2 产品边界

- 默认头像和角色头像以仓库中已登记、可发布且有授权的素材清单为准，不依赖某台开发机上的本地路径。
- 管理员账号的初始化、凭据轮换和安全存储由部署与运维流程负责；页面、代码和文档不预置管理员明文密码。
- 密码框的“显示/隐藏”只改变当前输入框的可见性，不在页面层自定义加密。
- 重置密码包含“确认新密码”，与注册和修改密码使用同一套密码校验体验。
- 账号数据、生产账号库和初始凭据不进入代码仓库版本管理。

## 3. 体验原则

1. **入口稳定**：无论是否登录，“个人”入口都可见；点击后根据身份进入相应首屏。
2. **状态可理解**：加载、成功、失败、禁用、未保存和权限不足不能只靠颜色表达。
3. **先保护数据**：离开有未保存修改的页面、执行覆盖本地数据等操作前，必须给出明确确认。
4. **反馈分层**：字段级问题紧邻字段显示；提交结果、网络问题和权限变化使用全局 `Message`；不会用全局提示替代字段错误。
5. **不暴露秘密**：密码和密保答案不回显、不写入 URL、不出现在日志或页面标题中；管理员可执行必要的重置动作，但不能查看现有密码。
6. **可恢复**：请求失败后保留用户已填写内容，并提供重试；认证过期时返回登录页，登录后尽量回到原目标页面。
7. **一致的响应式体验**：桌面端采用左侧设置导航，移动端将其改为紧凑的可访问选择器或横向标签，不复制两套业务规则。

## 4. 信息架构与入口

### 4.1 页面路径

以下路径是页面导航约定，不代表 API 契约。实现时应保持页面语义不变，并为已有 `/admin` 入口提供兼容跳转或等价入口。

| 页面 | 页面路径 | 进入条件 | 首要任务 |
| --- | --- | --- | --- |
| 个人入口 | `/account` | 所有人 | 未登录进入登录；已登录进入个人信息 |
| 登录 | `/account/login` | 所有人 | 登录账号 |
| 注册 | `/account/register` | 所有人 | 创建账号 |
| 忘记密码 | `/account/forgot-password` | 所有人 | 验证用户名和三个密保答案 |
| 重置密码 | `/account/reset-password` | 已通过密保验证或持有管理员一次性重置凭据 | 设置新密码 |
| 个人信息 | `/account/profile` | 已登录 | 查看和保存资料 |
| 密保问题 | `/account/security-questions` | 已登录 | 设置和保存三个问题及答案 |
| 修改密码 | `/account/change-password` | 已登录 | 使用原密码修改密码 |
| 数据同步 | `/account/sync` | 已登录 | 对单个数据项执行同步或查看 |
| 账户管理 | `/account/admin` | 管理员 | 查看和维护账号 |

### 4.2 “个人”入口规则

- 桌面端：在现有顶部导航的右侧增加“个人”标签，使用用户图标和文字；不登录时仍显示同一标签，不根据登录状态突然隐藏入口。
- 移动端：在现有底部导航中增加“个人”入口。六项无法在最小支持宽度下保持清晰时，允许导航横向滚动，但不得隐藏或缩写为无法理解的图标。
- 未登录点击：进入登录页。若目标页面来自需要认证的链接，登录成功后返回该目标页面。
- 已登录点击：进入个人信息页；若上次停留在个人设置的子页，可以恢复该子页，但首次进入必须默认显示个人信息。
- 管理员入口：账户管理只在管理员的设置导航中出现。普通用户直接访问管理地址时显示统一的“无权访问”状态，不展示账号列表内容。
- 登录后新创建或加入多人房间时，自动使用账号的多人游戏使用名称和当前头像作为房间身份，不再要求用户另选游客身份。已经以游客身份进入的房间保持原游客身份，不因登录而切换。
- 已登录用户在多人房间中执行“退出登录”时，先尝试离开当前房间，再清除登录状态并返回登录页。离开成功时，其他成员显示该用户已离开；离开请求失败或网络中断时，仍完成退出登录并提示房间状态同步异常，同时将该成员标记为已离开并向其他成员显示离开状态。

### 4.3 个人设置外壳

桌面端个人设置页由四部分组成：

1. 页面标题区：显示“个人”和当前子页面标题，可显示简短的状态说明。
2. 左侧设置导航：个人信息、密保问题、修改密码、数据同步；管理员额外显示账户管理。
3. 右侧内容区：只承载当前子页面，保存按钮放在内容区末尾并保持稳定位置。
4. 账号操作区：显示当前用户名和“退出登录”操作。若当前处于多人房间，退出前先尝试离开房间；完成退出后返回登录页，不展示受保护页面内容。设置页存在未保存修改时，退出登录也必须先进行二次确认。

移动端将左侧导航变为页面标题下的选择器或横向标签。切换子页不会清空其他页面已经保存的内容；存在未保存修改时，切换、返回和站点导航都必须先确认。

## 5. 全局状态与反馈

### 5.1 认证状态

| 状态 | 页面表现 | 可执行操作 |
| --- | --- | --- |
| 未登录 | “个人”入口正常显示；账号页显示认证入口 | 登录、注册、忘记密码 |
| 账号已停用 | 登录页显示“账号已停用，请联系管理员”；已有会话已失效 | 无法登录或访问受保护页面；多人房间按成员离开处理 |
| 正在加载 | 页面骨架或表单控件显示等待状态 | 不重复提交，不丢失已填内容 |
| 已登录 | 个人设置外壳和当前账号资料可见 | 访问授权页面、保存、同步、退出 |
| 登录过期 | 保留当前页面意图，提示需要重新登录 | 返回登录；成功后回到原目标 |
| 无权访问 | 显示标题、原因和返回个人信息按钮 | 不显示被保护数据 |
| 服务不可用 | 显示可重试的错误状态 | 重试或返回上一页 |

| 场景 | 消息 |

| 登录成功 | 登录成功 |
| 登录失败 | 用户名或密码无效 |
| 账号已停用 | 账号已停用，请联系管理员 |
| 注册成功 | 注册成功 |
| 注册失败 | 注册失败：{失败原因} |
| 找回验证成功 | 校验成功 |
| 找回验证失败 | 校验失败：{失败原因} |
| 密码重置成功 | 密码重置成功 |
| 密码重置失败 | 密码重置失败：{失败原因} |
| 资料保存失败 | 保存失败：{失败原因} |
| 头像更换成功 | 更换头像成功 |
| 密保保存成功 | 密保问题与答案保存成功 |
| 密码修改成功 | 密码修改成功 |
| 重置凭据生成成功 | 一次性重置凭据已生成，请在有效期内交给用户 |
| 重置凭据生成失败 | 重置凭据生成失败：{失败原因} |

按钮在请求期间显示等待并不可重复点击。失败后按钮恢复可用，表单输入保留；成功后只有在页面目标改变时才进行跳转。

## 6. 认证页面

### 6.1 登录

页面包含用户名、密码、登录按钮，以及两个辅助链接：密码框下方左对齐的“忘记密码？”，右对齐的“注册新账号”。

- 用户名和密码均为必填；按回车提交等同于点击登录。
- 用户名按大小写精确匹配；例如 `Alice` 与 `alice` 是两个不同的用户名，二者可以同时注册。
- 密码默认为隐藏，输入框内右侧提供显示/隐藏按钮，并为按钮提供当前状态的可访问名称。
- 点击登录后校验账号状态、账号是否存在和密码是否正确。账号状态为“停用”时拒绝登录并显示“账号已停用，请联系管理员”；其他失败显示“用户名或密码无效”，不透露是用户名还是密码错误。成功显示“登录成功”，进入原目标页或个人信息页。
- 登录请求失败不清空表单；网络失败与凭据错误使用不同的反馈文案。

### 6.2 注册

字段顺序为用户名、密码、确认密码、注册按钮。密码和确认密码均支持显示/隐藏。

| 字段 | 规则 | 触发时机 | 错误提示 |
| --- | --- | --- | --- |
| 用户名 | 仅字母或数字，长度 4 至 10；必须唯一，大小写视为不同用户名 | 失去焦点和提交时 | 用户名只能包含字母或数字，长度应在4和10之间；用户名已被占用 |
| 密码 | 不含空格，长度 6 至 256 | 失去焦点和提交时 | 密码不可带空格，长度应在6和256之间 |
| 确认密码 | 必须与合法密码完全一致 | 失去焦点和提交时 | 请先设置正确的密码；密码输入不一致，请重新输入 |

提交前应先显示所有能确定的字段错误，并把焦点移到第一个错误字段。仅当三个字段均合法且一致时才提交。注册成功后显示全局提示并进入登录页，不自动以新账号登录。

当 UID 分配达到当前位数上限、注册暂时停止时，注册页显示“当前暂不开放注册，请稍后再试”，保留用户已填写内容；该状态不应伪装成用户名或密码错误。

### 6.3 忘记密码

页面包含用户名输入框、“获取密保问题”按钮、三个只读问题框、三个答案框和“检验答案”按钮。

- 未输入用户名时，获取按钮不可提交；问题框显示“请先输入用户名”。
- 获取问题成功后按顺序显示该账号的三个问题，并启用对应答案框和检验按钮。
- 用户不存在、未设置完整密保问题或服务失败时，不显示任何已有问题答案，使用全局提示说明无法继续。
- 三个答案都必须填写。比较前先进行全角/半角归一化，再去除首尾空白，但保留大小写差异；输入框中的原文不在页面上静默改写。
- 验证成功显示“校验成功”并进入重置密码页；失败显示可理解的失败原因，但不指出具体哪一个答案错误。
- 密保答案校验失败计入该用户名与请求来源组合的失败次数；达到限制后，检验按钮进入冷却状态并显示剩余等待时间，冷却结束后才可再次尝试。刷新页面不能绕过冷却，取消操作和网络错误不计入失败次数。成功完成校验后，该组合的失败计数清零。

### 6.4 重置密码

页面显示通过密保验证或管理员一次性重置凭据得到的只读用户名、新密码、确认新密码和确认按钮。用户名不能由用户修改。

- 新密码复用注册页面的格式校验和错误提示。
- 只有新密码合法且两次输入一致时才允许提交。
- 成功显示“密码重置成功”，返回登录页；失败保留输入并显示“密码重置失败：{失败原因}”。
- 密码重置成功后，其他设备上的登录状态立即失效；用户需要在登录页重新登录。
- 密保验证授权和管理员重置凭据均有效 15 分钟且只能使用一次；密码重置成功、授权过期或授权被撤销后均不可再次使用。授权过期或被撤销时回到登录页；管理员重置凭据无效或已使用时提示“重置凭据已失效，请联系管理员重新发起”并回到登录页。
- 用户名被篡改或页面状态无效时，拒绝提交并回到对应的认证入口（密保流程回到忘记密码页，管理员凭据流程回到登录页），不展示内部原因。

## 7. 个人设置页面

### 7.1 个人信息

页面展示头像、用户名、多人游戏使用名称和 UID。

| 信息 | 默认值与限制 | 是否可编辑 |
| --- | --- | --- |
| 头像 | 创建账号时从默认头像池随机选择 | 可编辑 |
| 用户名 | 注册时的用户名 | 不可编辑 |
| 多人游戏使用名称 | 默认与用户名相同 | 可编辑 |
| UID | 普通用户按永久递增规则分配；管理员为 `000000` | 不可编辑 |

管理员的固定 UID 为 `000000`。管理员登录名和初始凭据属于安全配置，不在本页面、代码或本规范中预置；管理员账号的实际启用由部署和运维流程负责。

#### UID 分配

- `000000` 永久保留给管理员，普通用户从 `000001` 开始取得尚未使用的 UID；UID 永不回收或复用。
- 同一长度内的 UID 按以下顺序递增，字符集仅包含数字 `0-9` 和大写字母 `A-Z`：先分发全数字 UID（全零值不使用），再依次增加字母前缀长度。每个前缀对应的数字后缀从全零递增到全九，字母前缀按 `A-Z` 的进位规则递增：一个字母前缀时从 `A` 到 `Z`，两个字母前缀时从 `AA`、`AB` 直到 `ZZ`，之后以同样规则继续，直到全字母 UID。例如六位 UID 中，`999999` 的下一个是 `A00000`，`A99999` 的下一个是 `AA0000`，最终达到 `ZZZZZZ`。
- 当 n 位 UID 全部用尽时，在高位增加一位，切换到 n+1 位，并从全数字的 `00...001` 开始分发，直至该长度的最大值。例如六位空间达到 `ZZZZZZ` 后，七位 UID 从 `0000001` 开始，最终达到 `ZZZZZZZ`；八位 UID 依次从 `00000001` 开始。
- 系统最多支持 15 位 UID，实际启用的位数上限默认是 15 且不得超过 15；达到当前上限后暂停注册，必须由运维手动调整配置后再开放。若已经达到 15 位硬上限，注册保持暂停，等待后续容量扩展方案。调整上限只影响未来分配，不改变已经发出的 UID。
- UID 的展示值始终保持完整字符串，不因页面宽度或数字前导零而省略字符；用户和管理员均不能编辑 UID。

#### 头像选择器

- 点击当前头像后，在其右侧打开浮层；浮层有明确标题和关闭行为，点击外部区域或按 `Esc` 关闭。
- 浮层内按统一尺寸展示头像，单行最多 8 个，窄屏根据可用宽度减少列数；头像数量较多时仅浮层内部滚动。
- 候选列表先按素材清单顺序展示默认头像，再按角色首次出场顺序展示全部可用的角色头像；首次出场时间相同时按角色稳定 ID 排序。素材缺失或不可用的角色不出现在列表中。头像较多时只在浮层内部显示窄滚动条，不推动页面布局。
- 默认头像始终处于解锁状态。已解锁头像正常显示并可点击；未解锁头像使用灰度处理、不可点击，并以图标或文字表达“未解锁”，不能只依赖灰度。
- 更换成功后立即更新页面头像并显示“更换头像成功”；失败时保留原头像并提示原因。
- 用户在每日、随机或多人模式中猜出角色后，该角色头像可解锁。解锁保存失败不阻塞当前游戏，但应在个人页下次刷新时以明确状态提示重试。
- 当前头像路径失效时，页面按默认头像素材清单顺序回退到第一个有效头像，并提示用户保存修复后的选择。

#### 多人游戏使用名称

- 允许汉字、字母和数字，不允许空格或其他特殊字符。
- 长度为 1 至 10 个字符，一个汉字计为一个字符。
- 失去焦点时校验并在字段下方显示红色错误文本“多人游戏使用名称只能包含汉字、字母和数字，长度应在1和10之间”；提交时再次校验。

页面底部有“保存修改”按钮。没有改动时按钮可禁用；保存期间按钮显示等待。校验失败不发起保存请求，服务器失败保留草稿并显示“保存失败：{失败原因}”。

### 7.2 密保问题

页面顶部固定显示以下说明：

> 密保问题用于找回您的密码。请注意，由于我们暂不支持其他账号辅助验证方式，因此密保问题的答案将作为您找回密码的唯一凭证，请妥善保存您的答案。

下方纵向排列三组“问题下拉列表 + 答案输入框”。问题选项为：

1. 你的生日是几月几号？
2. 你目前居住的城市是哪里？
3. 你就读于哪所小学？
4. 你最喜欢东方的哪个角色？
5. 你最喜欢的东方原曲是什么？
6. 你玩过的第一部东方原作游戏是什么？
7. 你最喜欢东方的哪部作品？

- 三个问题必须选择且不能重复；答案字段暂不限制格式，但不能为空。保存和找回校验时先进行全角/半角归一化，再去除答案首尾空白，但不忽略大小写；页面保留用户实际输入的原文。
- 初始状态为三个空问题和空答案，不用默认问题替用户占位。
- 点击“保存密保问题与答案”时进行完整校验，合法后保存并显示“密保问题与答案保存成功”；非法或服务器失败时保留输入并说明原因。
- 页面离开时若有未保存修改，必须确认后才能离开。

### 7.3 修改密码

页面包含原密码、新密码、确认新密码和“确认修改”按钮。原密码和新密码均支持隐藏/显示，新密码复用注册页面的格式校验。

- 新密码失去焦点时显示字段级格式错误。
- 点击确认时必须同时通过原密码正确、新密码合法、两次新密码一致三项校验。
- 成功显示“密码修改成功”；失败显示修改无效原因，不清空输入。
- 修改密码成功后，其他设备的登录状态立即失效；当前设备保持登录，并显示明确的登录状态反馈。

### 7.4 数据同步

页面以可扩展的数据项列表展示“题库设置、游玩记录、曲库设置”等数据。未来新增数据项时沿用同一行结构，不改变其他数据项的行为。

每个数据项独立显示：名称、本地状态、云端状态、最近同步时间和可用操作。数据项之间不得互相阻塞或覆盖。

| 操作 | 行为 |
| --- | --- |
| 同步至云端 | 将该项当前本地数据保存为账号资产；显示等待和全局结果提示 |
| 同步至本地 | 将该项云端数据覆盖本地数据；点击后先显示“当前操作将会永久覆盖本地数据并无法恢复，是否继续？”；确认后才执行 |
| 查看当前数据 | 复用该数据已有的对话框或查看组件；不修改数据 |

“游玩记录”暂不提供“查看当前数据”按钮，沿用现有统计页展示。只有本地或云端单侧存在数据时，可以直接执行对应的单向同步，不进入冲突预览。取消确认不产生任何数据变化；覆盖失败时保留原本地数据并允许重试。同步操作只更新当前数据项的状态，不刷新或重置其他数据项。

当本地和云端数据都存在且内容不一致时，先进入冲突预览。预览中的可读摘要以数据差异为主，展示两侧的具体变更项、更新时间和来源；题库设置和曲库设置列出新增、删除或修改的具体设置，游玩记录只展示记录数量、时间范围等统计摘要，不展示完整记录列表。差异项较多时，可以按数据类别折叠或对差异列表分页，并明确显示变更项总数；展开或翻页不得改变待保留的版本。用户只能选择“保留本地并同步至云端”或“保留云端并同步至本地”其中一个整体版本，不提供字段级合并。取消预览不产生数据变化。选择完成后，所选版本整体覆盖另一侧，操作结果使用全局 `Message` 反馈。

冲突预览打开期间，如果本地或云端数据再次发生变化，当前预览立即标记为过期并禁止覆盖操作；页面提示“数据已更新，请重新载入”，用户重新载入最新差异后才能再次选择保留的整体版本。

同步采用“用户主动发起、按数据项独立处理”的体验。同步请求失败时保留两侧原数据，并允许用户重新打开预览或重试。

## 8. 账户管理

账户管理只对管理员可见并可访问。页面采用常见的管理列表加详情布局，优先保证检索、比较和单账号维护效率。

### 8.1 账号列表

列表至少包含：UID、用户名、最近登录时间、账户登录时间（按注册时间展示）和账号状态。这里的“账户登录时间”指注册时间；“最近登录时间”单独表示最近一次成功登录。账号状态仅有“正常”和“停用”两种业务状态，失败次数触发的短暂冷却不改变账号状态。当前范围支持展示和按状态筛选，不提供管理员停用或启用账号操作。账号进入“停用”状态后，禁止新登录，使已有登录会话失效，并让其在多人房间中按成员离开处理、向其他成员显示离开状态。默认按 UID 升序排列，并允许切换按用户名、注册时间、最近登录时间等其他列表字段排序。支持按用户名进行大小写不敏感的模糊匹配，或按 UID 查找，支持分页；用户名占用检查仍采用大小写精确匹配。空结果、加载失败和无权访问均有独立状态。

点击一行进入账号详情，返回列表时保留此前的筛选和分页位置。

### 8.2 账号详情

详情页分组展示基本资料、安全设置状态、头像解锁概况和数据同步状态。密码和密保答案只显示“已设置/未设置”等状态，不显示原文。

管理员可以在授权范围内编辑用户的头像、多人游戏使用名称和其他非秘密资料，可以发起密码重置、清除密保设置或强制用户下线；每项操作都必须明确说明影响并使用全局 `Message` 反馈。UID 和用户名属于账号识别信息，默认不可修改。

- 清除密保设置前二次确认：“清除后该用户将无法通过密保找回密码，是否继续？”
- 强制用户下线前二次确认：“该操作将使该用户在所有设备上的登录状态失效，是否继续？”
- 发起密码重置前二次确认：“将生成一份 15 分钟内有效的一次性重置凭据，用户使用后可设置新密码，是否继续？”
- 确认后生成一次性重置凭据，页面仅展示凭据、有效期和复制操作一次；关闭后不再显示，管理员需要新凭据时重新发起。管理员不能设置或查看临时密码，用户使用凭据进入重置页设置新密码，凭据使用一次后立即失效。
- 用户取消确认时不产生变化；确认后显示操作结果。强制下线允许管理员对自己执行，并使该管理员在所有设备上的登录状态失效；若当前会话也被下线，操作完成后立即回到登录页。管理员不能查看用户现有密码或密保答案原文。
- 清除密保和强制下线属于敏感操作，连续失败达到限制后进入冷却状态；按钮显示剩余等待时间，取消确认不计入失败次数。

普通用户不可通过修改 URL、缓存或页面状态绕过权限检查。管理员页面出现权限变化时，应立即停止编辑并显示无权访问状态。

## 9. 可访问性与响应式要求

- 所有输入框有可见标签，错误文本通过关联关系暴露给读屏器。
- 键盘可以完成表单填写、提交、浮层打开/关闭、头像选择和页面切换；浮层打开后焦点不会丢失。
- 头像具备角色名称和解锁状态的可访问名称；未解锁项不可获得点击焦点。
- 成功、错误、等待和禁用状态同时使用文字、图标或结构表达，不能只改变颜色。
- 表单在 320px 宽度下不发生横向溢出；按钮文字、错误文本和确认提示不被截断。
- 遵循现有深浅色主题、主题色和减少动态效果设置；浮层、确认框和全局消息不能遮挡关键表单操作。
- 认证和设置页面不依赖鼠标悬停才能发现重要操作。

## 10. 数据与隐私边界（用户可见行为）

- 未登录用户仍可使用现有无需账号的每日题、随机题和游客多人功能。
- 登录不会自动覆盖本地统计；用户必须在数据同步页逐项发起同步。
- 页面不展示或复制密码、密保答案等秘密值；复制、导出和分享功能不得包含这些值。
- 头像解锁和资料修改应在成功后立即反映在当前页面；后台保存失败必须可见但不阻塞正在进行的游戏。
- 默认头像和角色头像仅使用仓库中已登记来源和授权的素材；本地开发机上的临时素材不构成产品资产。

## 11. 跨页面规则

以下规则适用于认证与管理员操作，所有相关页面必须保持一致。

### 11.1 失败限制规则

以下阈值和冷却时长是认证与管理员操作的正式页面规则：

| 场景 | 阈值 | 冷却时间 | 计数重置 |
| --- | --- | --- | --- |
| 登录凭据错误 | 连续 5 次 | 15 分钟 | 成功登录后清零；冷却结束后清零 |
| 密保答案错误 | 连续 5 次 | 30 分钟 | 成功完成找回校验后清零；冷却结束后清零 |
| 管理员生成重置凭据、清除密保或强制下线失败 | 连续 3 次 | 10 分钟 | 同类操作成功后清零；冷却结束后清零 |

达到阈值后，相关操作进入冷却并显示“尝试次数过多，请在 {倒计时} 后重试”。页面只显示倒计时，不显示剩余失败次数；取消确认和网络错误不计入失败次数。冷却状态需要在刷新页面后继续生效，不能通过重新打开页面绕过。

失败计数按操作场景独立维护：登录凭据错误按“输入的用户名 + 请求来源”计数，用户名不存在也按同样规则计入；密保答案错误按“用户名 + 请求来源”计数；管理员敏感操作按“当前管理员账号 + 具体操作类型”计数，生成重置凭据、清除密保和强制下线互不影响。只有服务端确认的失败会计入，取消确认和网络错误不计入；不同计数组合的冷却状态互不影响。

密保校验成功后的重置授权和管理员生成的重置凭据有效期均为 15 分钟，只能使用一次；密码重置成功或授权到期后立即失效，授权到期时回到登录页。

## 12. 文档验收标准

本规范进入后续 issue 拆分前，应满足：

- 每个页面都有明确的进入条件、字段、操作、成功结果和失败结果。
- 登录、注册、找回密码和重置密码能够从入口到完成形成闭环。
- 个人资料、密保、改密和同步四个设置页的保存及未保存行为互不混淆。
- 管理员与普通用户的可见范围、可编辑范围和秘密信息展示边界明确。
- 桌面端和移动端的导航、浮层、表单和确认操作都有响应式要求。
- 本规范确认后，才能按页面、认证基础、资料设置、同步和管理视图拆分开发 issue。
