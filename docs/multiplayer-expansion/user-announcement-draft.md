# 多人房间扩展公告草稿

> 状态：草稿，待 MPX-010 发布闸门通过后复制到 `content/announcements/` 正式发布。
> 建议标题：多人房间开放：N 人竞速与房间聊天
> 建议日期：随默认开放日期填写。

多人房间扩展将默认开放。本次开放包含 N 人竞速、房间聊天和闭麦设置；若遇到回滚或临时关闭，公告会同步更新。

## 已经上线

双人竞速和双人接力房间仍保持原有玩法：房主创建房间，另一名玩家输入 6 位房间号加入，双方准备后即可开始。观战者可以在房间未满或对局开始后进入观战。

## 本次开放

N 人竞速支持由房主设置 `playerLimit`，范围为 2 到 8。`playerLimit` 是房间容量上限，不是必须凑满的人数；只要至少两名玩家在线并且当前玩家全部准备，房间就会按当时阵容开局。

当实际开局人数超过 2 人时，竞速会使用积分淘汰制：每局按猜中顺序计分，后续轮次淘汰累计积分较低的玩家，直到产生最终排行榜。淘汰或离场后的玩家会转为只读观战视角。

房间聊天会在多人游戏页面显示。玩家消息对玩家和观战者可见；观战者消息只对观战者可见。聊天仅支持文本和内置白名单 Unicode 表情，不支持图片。使用闭麦按钮后，本浏览器不会显示他人新消息，也不能发送消息；重新开启后不会补弹闭麦期间的提示。

## 兼容提示

旧页面需要刷新后才能进入新版多人房间。灰度切换期间，短期旧协议房间可能会排空或关闭；已经进入新版房间的玩家仍可安全结束当前对局。若功能被临时关闭，新建 N 人房间和发送新聊天消息会暂停，已有房间仍可读取授权历史并完成对局。

## 暂不支持

本次不包含组队玩法、N 人接力、队内聊天、图片消息、账号化身份、管理员审核、禁言或举报后台。这些能力需要单独设计和测试，不会在本次灰度中开放。

更多规则请查看多人玩法说明：`docs/multiplayer.md`。正式发布时请替换为站内可点击链接。
